## Changes after the lanes' reviews (2026-11-01)

From ASTRA's review (review_20261101/astra.md) — adopted:

  scene list, output names, timeout) so a setup slip costs seconds, not hours. W12 entry smoke keeps the packaged
  earned resume (save/reload) check; lint stays narrow (scenes/resources only, raw JSON/media may use FileAccess).

  re-prompts at known times, or an API/CLI worker), plus task LEASES (lane + task + worktree in status/<lane>.md),

  behaviour the book already describes.
- W20 changed: PROGRESS.md separates audited / implemented / headless-qualified / rendered-qualified story steps and
  names the build each count describes.
