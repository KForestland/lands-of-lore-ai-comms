# LoL3 planning phase (owner direction 2026-11-03) - DRAFT checklist

Owner: plan first and gather material, then run the LoL2 workflow optimised for LoL3. Be looser on the game world
(LoL3 was rushed and buggy). Enhanced Edition fixes story elements: rushed writing, fit to the Chronicles of Time
timeline, and above all the SOULS storyline, which today has no payoff or effect on the story.

## 1. Gather before building (planning phase)
- [ ] Strategy guides / walkthroughs (official LoL3 guide if any, fan walkthroughs, the landsoflore.de material)
- [ ] Longplay videos (full playthrough, plus one per guild path if paths differ), with a frame index like LoL2's
- [ ] Owner notes: what he remembers, what felt broken or rushed, and what to keep exactly
- [ ] Known bug lists and patches (official patches, fan fixes)
- [ ] RE status: lands-of-lore-3-re, lol3_out, LOL3_CLASSIC_PREP.md status table, LOL3_MASTER_PLAN.md
- [ ] Story map: guilds, factions, the souls thread, the Dracoid / Ruloi / Belial threads, endings

## 2. LoL2 workflow, optimised for LoL3 (from LESSONS_LOL2_DRAFT_20261103.md)
- Engine first, not retrofitted: shared area host, one-owner registry, earned-chain fixtures, playtest start points,
  stage manifest, save migrations.
- Phase order that held up: maps -> progression from the guides -> items -> RPG -> dialog -> small fixes.
- Research lane (Grok) ahead of the builder (Astra): story cards + source-id packs per area before building.
- An early playable slice so the owner playtests real builds within the first weeks.
- Known behaviour -> build directly; decode only unknowns; logged adapters.

## 3. Classic vs Enhanced for LoL3
- Classic: the original game, bugs fixed (ledger as in LoL2), "looser" on world detail where the original was
  rushed: logged adapters are fine.
- Enhanced:
  - fix rushed story elements;
  - fit the Chronicles of Time timeline;
  - give the souls storyline real consequences (owner + story bible decide);
  - LoL 1-3 Enhanced compatible with each other.

## 4. Open questions for the owner
1. Which guides/walkthroughs/videos do you already have (paths)?
2. The souls storyline: what should the payoff be? (story bible / CoT outline)
3. Start LoL3 planning in parallel with LoL2 Act 3 (research only), or after LoL2 is done?

## Owner answers 2026-11-03
1. Sources: a web scrub (archive.org and many other places) plus the videos we already have.
2. Enhanced LoL3 (at least 2 years out):
   - Souls payoff: a synthetic soul, and getting the soul back in pieces from bosses.
   - Fix the gimmick worlds.
   - Rework the C&C world into something else, since it cannot be used: a small hub of normal humans, tied to the LoL6
     main villain experimenting with the timeline.
3. Order: LoL2 Classic -> LoL3 Classic -> LoL1 Classic; then Enhanced/modernized LoL1 -> LoL2 -> LoL3.
   Enhanced world design:
   - one Gladstone map in 3 time periods, with architecture changes;
   - the White Tower in all 3 periods;
   - Metro-style open-world maps with Skyrim-like landmarks;
   - the Northern Forest as real trees; mountains as map borders.

## Enhanced prototype (owner 2026-11-03)
Option 2 agreed: an Enhanced vertical slice of the shared Gladstone map in 2-3 time periods, with the White Tower as the
landmark. It tests time-period swaps, landmark-led open layout, asset style and modern lighting, and becomes the first
real Enhanced asset. Timing: AFTER the Classic work is done. (A Metroid Fusion remake was declined: no recreations of
existing games, and Nintendo's takedown record.)

- Luther steals the Atlas from the Gladstone library and hides in the Thieves' Guild (or elsewhere).
- Guards catch him in a playable chase; he is judged by the king's evil right-hand man.
- It shows Gladstone and Luther's relationships, then he ends up in the Cave where LoL2 begins.
- Classic keeps the original intro.
