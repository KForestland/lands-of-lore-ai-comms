## Problems

1. **DEVIATIONS.md hunks stale in both Fable patches** — they don't apply at 64e84ea with default context. Merge must use `-C1`/3-way or `--exclude=docs/DEVIATIONS.md`, then run `python3 tools/build_deviations.py build` and `--check` (the render order differs from hand-append order, so this step is mandatory, not optional).
2. **Minor BI10 edge case, untested** — `l8_straw_trap.gd` `restore()`: if the player saves *after escaping* (sprung, on grass), a reload computes `show = sprung and _on_pit_floor()` = false → ramps hidden, lid gone, straw still drawn — the pit looks covered but isn't until the next fall re-shows the ramps. Survivable and self-correcting, but a visual/state inconsistency the earned test doesn't cover. Follow-up, not a blocker.
3. **Atlas: 5 of 12 plot markers have `"done": []`** (`larkhon_must_sleep`, `larkhon_ask_shaman`, `larkhon_serum_needs_leaf`, `larkhon_vapors_unactivated`, `l10_trees_need_dawn`) and never clear, which the spec's point 3 ("markers clear when the step is done") doesn't cover — though the Jungle table (row 0341) already set this precedent with two such rows. Note only.
4. **Registry order duplicates** — 935 (torch vs bacatta voice) and 936 ×2 (straw trap, atlas). Tolerated by existing practice; flag in case the runner ever assumes uniqueness.
