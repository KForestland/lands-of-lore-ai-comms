# AX01 Act 3 main-chain triggers, STORY-066 through STORY-093

Base is live `stack-ah01` `381b841` plus the unapplied AH02 stack and the unapplied AR01 and AR02 diffs. AR03 only rewords `AH02_act3_stack/ORDER.md` and is not a game-tree diff. No AX patch is applied. Grades stay separate: HINTBOOK is `reference_hintbook/hintbook.txt`, FRAME is `grok_research/I33_act3_frames.md`, DECODED is `scripts/lol2/act2_travel.json` and the script comments that quote a native record. Prima page numbers below are the sentences already written in `act3_duck.md`. They are not merged with Brady.

A walk-past is a step the original starts by entering a place, while the port waits for E, so a player can stroll through and the chain never arms. Click, item, dialog, and spark steps can be skipped by leaving the hotspot. That skip matches the book, so those rows are not the temple pattern.

The host fires a region event when `region_at` changes. `act2_progression.gd` `enter_region` calls `fire("region:N", 2, {})`. Kind-12 event 2 on that region therefore runs on the crossing. I31 did not prove native enter versus stand versus leave. This note says what the port does.

Two quest reads sit between drafts. `l16_ne_tower.gd` sets `at_doors` only after `l16_greenhouse.opened`. `l16_centre_tower.gd` sets `at_bars` only after that `at_doors` flag. No other new script reads a previous quest key to refuse a level change. E-only flags do not gate regions 233, 1312, or 2369.
