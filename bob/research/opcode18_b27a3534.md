## Entry tests seen this pass

At 0x65BB0 the prologue takes the command pointer from the stack into esi. Then:

```
65BC8  mov ax, word ptr [esi + 0xA]
65BD0  test al, 0x20
65BD2  je 0x65BDB
65BD4  mov al, 3
65BD6  jmp 0x660EF
```

Byte +10 of the command is the flags word. `test al, 0x20` is flag 0x0020 on that word, and the fall-through return value in al is 3. That is their already-complete return, read here, not imported from the other hash.

The next test in the same function:

```
65BF4  mov al, byte ptr [esi + 1]
65BF7  cmp eax, 1
65BFA  jne 0x65C21
```

Byte +1 compared with 1 is their kind-1 branch. The branch target 0x65C21 is the other arm. The rest of their flag table (0x0004, 0x0100, 0x0080, 0x0800, 0x0008) was not re-derived instruction by instruction this pass. No differing byte was found inside the hashed interval, so those readings are readings of these same bytes. They were not re-proven one flag at a time, and the gradual helpers were not entered.
