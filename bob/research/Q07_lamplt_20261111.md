## What those bytes do

PROVEN for the stores. `0xA23BD` is `mov al, [ebp-0x1f]`. `0xA23C0` stores it at actor `+0xA8`. `0xA23D1` loads that byte. `0xA23D7` compares with `0x10`. `0xA23DA` jumps if below. `0xA23DC` stores 6 otherwise. Fourteen stays. `0xA242C` loads `+0xA8` and `0xA2438` copies it to `+0xA9`.

Goal names in `global\ai\globalai.csv` are 14 labels, indexes 0–13. Index 6 is Wander. Index 14 is past that list. `0x59D58` runs only when `+0xA9` is below 14 (frame-event note). The 52 therefore do not take a named goal at spawn. The 14 with byte 6 start on Wander. The selector `0x59DAC` was not run on the LAMPLT profile, so the goal it would pick from previous byte 14 is UNKNOWN.

Bit `0x1000` is the unlinked bit in the cave-guard note: the actor is not linked until opcode 9 property 3, handler `0xB50C0` operation 3, clears it. That handler was not re-entered here. Grade LIKELY that actors 24–28 start unlinked for the same bit. The population field `present: false` is that bit. Bit `0x2000` separates the west nine from the other 57. Its reader was not found in this pass. UNKNOWN as a hostility switch beyond that split.

No flag in this set is a night mask. LAMPLT `stat.csv` leaves Wakefulness empty, which the parser treats as 0. The distance gate below does not read a clock. A separate night script was not found. They are not "only at night" in these bytes.

The distance gate is `verify_hive_perception_definition.py` and `verify_hive_perception_distance.py` on this executable: in range when the whole-unit distance is at most near+falloff. For these records that sum is 125 on the first channel and 1250 on the second. The third channel's sum is 0. The facing test keeps a target when the folded heading difference is at most `angle/2`. For 65353 that half is 32676, and the fold's maximum is 32767, so only a thin wedge fails. Those verifiers supplied a definition image. They were not re-run with the LAMPLT bytes loaded through `0x118820`. The file words sitting in the 0x87-byte copy are LIKELY, the same grade as the reach word in Q06.

The blow bit is Q06, re-read here. `0xA4E54` loads byte `+0x9E`. `0xA4E5F` (file `0xDBE5F`) is `test ch, 6`. If bits 1 and 2 are both clear, `0xA4E62` jumps to `0xA4EE9` and clears `+0xB7` bit 0. Otherwise `0xA4E7B` compares the octagonal distance with the reach word in 16.16. LAMPLT's word is 0, so the bit is set only at distance 0, and only when one of those perception bits is already set. The facing channel ORs 2 into its flag byte when the target is visible inside the first gate (`hive_perception.gd` `facing_channel`). Copying that byte from `+0x9C` to `+0x9E` is the executioner path in the hive admission note. That copy was not re-run for LAMPLT. Grade LIKELY for "the 125-unit channel is what raises the bit the blow test requires."

They are not hostile on sight everywhere. The first channel stops at 125. They are not melee-reach 50. The book's "poison from a distance" is not this reach word. A projectile writer was not entered.
