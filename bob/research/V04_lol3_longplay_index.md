## 30-second frame clock

Same shape as the LoL2 Act 2+ index. That index is 401 frames, 30-second steps, from 109:40 to 309:10, with `t = 6580 + (N-1) * 30` seconds, because the useful film starts at 109:40. The LoL3 clock starts at the first playlist part.

Use the Leo playlist, in the order the playlist page lists.

- Frame 1 is t = 0, the first sample of part 1.
- Frame N is t = (N-1) * 30 seconds along the parts concatenated in that order.
- A part boundary does not reset N. The next part continues the same t.
- The file name, when a later pass extracts frames, is `lol3_longplay_frames/frame_NNNN.jpg`, four digits, matching that N.
- No directory was created. No mp4 was copied.

The other three playlists can use the same formula on their own order. They are not a second guild clock. A part title is the only guild evidence until a frame is looked at.
