After the first non-player op18 runs anywhere (e.g., L16 g14030 kind-3, L14 g1360 kind-16), every later native player pose silently stops firing for the rest of the session — the field persists across level changes in the native bank. Row 0375 discloses "a command that does not pose leaves the slot full" but not this consequence: the native pad/1293/birth poses can never be qualified while prop/control op18s run first.
