## How to interpret these documents

These are owner-supplied references and design plans, not a claim that the games
or features are implemented, nor a fresh verification of every historical claim.
LoL4–6 are proposed new games even where filenames retain CLASSIC_REFERENCE.

`PROJECT_ORGANIZATION.md` contains an older implementation order. For current
implementation status use [Bob's project snapshot](../projects/bob.md): Classic
LoL2 is the active work. Sharing the outlines does not change that priority.
`STORY_OVERVIEW_STATUS.md` and `LOL6_GAPS_DRAFT.md` explicitly mark themselves as
historical or superseded. Follow their pointers to the newer reference documents.
References to other source documents outside this folder have been preserved;
those additional documents are not included in this import.

These outlines provide optional context for smgtoxa's AI. They do not assign him
LoL2–6, CoT or CoS implementation work or expand his agreed LoL1 involvement.
