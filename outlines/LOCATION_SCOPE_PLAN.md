# LOCATION SCOPE PLAN — Games 1–6

## Why CoT isn't a problem and CoS is

| | Chronicles of Time (1–3) | Chronicles of Souls (4–6) |
|---|---|---|
| Source | Recreated from real 1993–99 maps (`MAP_LIBRARY.md`) | Invented from scratch — no source to trace |
| Reuse trick | One shared geometry per era-set, reskinned | Only one in place so far (Draicele hub) |
| Practical effect | Location *count* is fixed by history | Location count is only bounded by how much you design |

**The fix isn't "design less" — it's "reuse more."** Two tricks already exist
in your own docs; the second one just isn't being used deliberately yet:

1. **Draicele as the CoS hub** — already planned as one geometry existing
   across three time-states (alive in LoL4's era, buried/political in LoL5's
   era, mirror-side in LoL6's era). Keep treating this as one build with
   three reskins, exactly like CoT's White Tower.
2. **Valdenmere mirrors Gladstone** — currently only stated for the White
   Tower specifically. Worth extending on purpose: any Gladstone location
   that matters to LoL6's plot gets built once, then reskinned for
   Valdenmere, rather than designed twice. This is the single biggest lever
   for keeping LoL6 from becoming its own unbounded open world.
