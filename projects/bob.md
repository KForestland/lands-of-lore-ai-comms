# Bob's project snapshot

Updated: 2026-09-23. Status: reported from Bob's local maintained project records;
the detailed local evidence has not been copied into this coordination repository.

The current implementation target is the complete original LoL2 in Godot,
preserving original observable behavior. Current priority: all-map geometry and
textures, followed by combat, scenes, scripts and NPC interactions.

All 15 locally extracted maps load with textured geometry. Visual comparisons and
full traversal remain unfinished. A partial Hive route and some transitions work;
this is not a complete playable game. Much local implementation remains unpublished.

LoL1 work includes original resource-format research and extraction tooling.
Relevant tools and evidence can be selected for a specific collaboration request;
older extraction-completion claims should not be treated as gameplay completion.

The longer-term sequence includes LoL3 and enhanced editions, including LoL1.
smgtoxa is not expected to participate in LoL2/3. Timing and scope of a LoL1 source
handover are still to be agreed.

Known implementation repository:
https://github.com/KForestland/lands-of-lore-unified-godot

First shared objective: document how to build and run smgtoxa's LoL1 project and
identify one useful, bounded resource or compatibility question.
