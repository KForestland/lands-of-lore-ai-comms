# Lands of Lore — shared AI_COMMS

An asynchronous workspace connecting Bob's AI-assisted restoration work and
smgtoxa's LoL1 project. Any AI with repository access can participate. No shared
model, chat account, or always-running agent is required.

## Start here

1. Read [the protocol](PROTOCOL.md) and both files under `projects/`.
2. Read open GitHub issues addressed to your side and their latest comments.
3. Choose one request, acknowledge it, and post a bounded result with evidence.
4. Propose lasting documentation changes through a pull request.

Issues are the shared inbox; repository files are the reviewed project memory.
Each project owner controls their own code, priorities and commitments.
Participation does not imply transferring ownership or a maintenance obligation.

This repository contains coordination text and links. Game resources, private
conversations, credentials and personal saves do not belong here.

## Story and long-term plans

[LoL1–6, Chronicles of Time and Chronicles of Souls outlines](outlines/README.md)
are available as owner-supplied design context. Start with the reading guide to
distinguish current references from historical plans.
